\# Dungeon Survivor



A 2D top-down fantasy dungeon crawler developed with Unity 6.



\## Game Concept

Explore dungeon rooms, fight monsters, avoid traps, collect gold and equipment, and defeat bosses to progress through increasingly difficult levels.



\## Platform

\- Android

\- iOS

\- Landscape orientation



\## Gameplay

\- Top-down movement

\- Melee combat

\- Dungeon exploration

\- Enemy encounters and boss fights

\- Gold and equipment progression

\- Hub with a portal and upgrade table (planned)



\## Controls

\- Virtual joystick — movement

\- Attack button — melee attack

\- Pause button — pause menu



\## Current Development Status

\- Main Menu implemented

\- Settings panel implemented

\- Pause Menu implemented

\- Mobile HUD implemented

\- Safe Area support added

\- Core gameplay mechanics are planned for future development
